# Apps

PWA front-ends for each role in the Nisia platform.

- **evia** — Apprentice app for evidence capture, learning hours, rewards
- **milos** — Assessor app for reviews, observations, judgements, mileage
- **symi** — Tutor app for sessions, registers, OTJ delivery
- **paros** — Employer app (link-based, sign & view)
- **nisia-web** — Platform dashboard for managers, quality, admin (online-first)

Each app imports from `packages/*` and uses the same data model, design system, and sync engine.
