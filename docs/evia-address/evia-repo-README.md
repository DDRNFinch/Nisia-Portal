# Evia has moved into Nisia

Evia is now edited in **[DDRNFinch/Nisia-Portal](https://github.com/DDRNFinch/Nisia-Portal)**, in `apps/evia`, alongside Milos, Paros, Symi and the Nisia portal. Its full history came with it.

**Don't edit Evia here.** This repository only publishes it: `.github/workflows/publish-from-nisia.yml` takes `apps/evia` from Nisia's main branch and puts it at Evia's own address (the one learners installed), so nobody has to reinstall and everyone keeps their saved work. It checks every hour and publishes when there's a new version.

The code that used to be here is still in this repository's history.
