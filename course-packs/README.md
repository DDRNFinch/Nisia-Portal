# Course Packs

Source `.nisi` course pack definitions for English apprenticeship standards.

These are moved from Milos and become part of the Nisia registry served by the platform.

Each pack contains:
- Standard code (e.g., `ST0095`)
- Codes and code descriptions (knowledge, skills, behaviours)
- OTJ minimum hours
- EPA settings

Course packs are versioned and pinned to enrolments so a learner's criteria never change mid-journey.
